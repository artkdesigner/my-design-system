# Рабочая среда продуктового дизайнера

Базовая среда для работы с Claude Code (Claude Opus 4.8). Здесь агент получает контекст о том, кто вы и как вести дизайн-задачи, а вы — место для артефактов.

Принцип: минимальный фундамент, наращивание только нужного.

## Что есть сейчас

| Что | Где | Состояние |
|---|---|---|
| Память проекта — правила и договорённости, читаются каждый раз | `CLAUDE.md` | готово |
| Артефакты по проектам | `projects/<имя>/` | пусто, ждёт первой задачи |
| Подключение к Figma (Dev Mode MCP) | `.mcp.json`, описание в `mcp/SETUP.md` | подключено |
| Каркас под скиллы | `.claude/skills/` | пусто намеренно |

## Что добавляется дальше

- **MCP-подключения.** Figma подключена, дальше по надобности браузер и источники данных. Подробности в `mcp/SETUP.md`.
- **Скиллы.** Когда задача повторилась и стало ясно, как её делать правильно — она превращается в `SKILL.md`. Кандидаты: продуктовый ресёрч, сборка экранов, работа с дизайн-системой.
- **Субагенты** (`.claude/agents/`). Когда задача перестаёт помещаться в одно окно контекста — крупная работа дробится на отдельных агентов со своими инструментами.
- **Тонкая настройка.** Хуки, свои slash-команды, режим плана — на зрелом процессе, когда есть что автоматизировать.

Ничего из этого не ставится заранее.

## Структура

```
.
├── CLAUDE.md              — спецификация среды + память проекта
├── README.md              — этот файл
├── .mcp.json              — подключение Figma Dev Mode MCP (без секретов)
├── .claude/
│   └── skills/
│       └── README.md      — каркас под будущие скиллы
├── mcp/
│   └── SETUP.md           — как устроено подключение, что умеет Figma MCP
└── projects/
    └── README.md          — сюда складываются артефакты задач
```
