# Скиллы

Здесь живут скиллы — папки с файлом `SKILL.md`, в котором лежит инструкция под одну конкретную задачу.

Как это работает: агент видит только короткое описание скилла и подтягивает полный текст, когда задача действительно к нему подходит (прогрессивное раскрытие). Поэтому скилл — это не общая памятка, а пошаговый рецепт: когда применять, что сделать, что считать результатом.

Структура:

```
.claude/skills/
  <имя-скилла>/
    SKILL.md          — инструкция (frontmatter: name, description)
    references/       — опционально: длинные материалы, шаблоны, примеры
```

Типичные кандидаты для дизайнерской среды: продуктовый ресёрч, сборка экранов в Figma, работа с дизайн-системой, подготовка кликабельного прототипа.

**Сейчас здесь пусто — намеренно.** Базовая среда ставит только фундамент. Скилл заводится тогда, когда задача повторилась и стало понятно, как её делать правильно; писать скиллы «про запас» смысла нет.
